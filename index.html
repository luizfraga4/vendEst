Este sistema foi desenvolvido sob a arquitetura BMAD para rodar 100% offline. Todos os dados permanecem salvos localmente na base de dados IndexedDB do seu navegador.

Recomendação: Faça downloads de backup em JSON periodicamente para salvar cópias de segurança de seu estoque e histórico de vendas.
